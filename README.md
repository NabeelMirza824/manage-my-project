**Part of the EVAITCS Full Stack Developer Curriculum**
**Application:** FindThatCream 🍦

---

## 📌 Project Overview

This project simulates a real-world Agile sprint for **FindThatCream** — a mobile-first web application that helps users discover premium ice cream flavors and find out exactly which retailers carry them.

As part of the EVAITCS 28-project curriculum, this project covers professional project management skills including sprint planning, daily standups, Kanban boards, and sprint reviews — all grounded in the FindThatCream application domain.

---

## 🎯 Sprint Goal

> Enable admins to securely log in and manage ice cream products, brands, and retailer assignments so the app has real data ready for users to browse.

---

## 🍦 About FindThatCream

FindThatCream is a mobile-first web app that solves a real problem for premium ice cream lovers — finding out which local and national retailers carry the best new drops from top brands, all in one place.

**Target Retailers:** Whole Foods, Wegmans, Mom's Organic, Trader Joe's, Target, Publix, Harris Teeter

**Featured Brands:** Jeni's, Van Leeuwen, Häagen-Dazs, Dolcezza, Tillamook, McConnell's, Alec's, Ice Cream for Bears, Graeter's

**Tech Stack:** Spring Boot · React · MySQL · JWT Auth · Oracle Cloud
